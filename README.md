# Reclaim

App móvil para **reportar y recuperar objetos perdidos**. Permite publicar reportes, buscarlos y ver el detalle de cada objeto.

## Funcionalidades

- Registro e inicio de sesión de usuarios
- Reporte de objetos perdidos
- Búsqueda y detalle de objetos
- Perfil de usuario

## Stack

- [Ionic 8](https://ionicframework.com/) + [Angular 18](https://angular.dev/)
- [Capacitor 6](https://capacitorjs.com/) para mobile
- [Firebase](https://firebase.google.com/) (Auth y Realtime Database)

## Cómo ejecutarlo

```bash
cd app
npm install
npx ionic serve
```

> Configura tus credenciales de Firebase en `src/environments/` antes de ejecutar.
